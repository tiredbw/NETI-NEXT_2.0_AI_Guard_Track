# Промпт: доводка фронта и мелкие ошибки перед защитой

Задание для участника 3 (фронт и демо) или Claude Code. Основа — [FRONTEND_PROMPT.md](FRONTEND_PROMPT.md) и текущий `main`.

---

## Промпт

Интерфейс «ИИ-сторожа» уже работает с Rust-бэкендом с одного адреса. После того как журнал, входящие агента и политика закрылись токеном (`ADMIN_TOKEN` — чтение и изменение, `AUDIT_TOKEN` — только чтение), а внешние вызовы `/v1/check` стали храниться в журнале без текста, во фронте и моке остались расхождения и мелкие ошибки. Исправь их, не меняя контракт `/v1/check` и не ослабляя закрытие журнала.

Ограничения прежние: чистые HTML/CSS/ES-модули без сборки и CDN, пользовательские данные только через `textContent`, токен только в памяти вкладки, стили только через токены из `css/app.css` (см. [frontend/DESIGN.md](../frontend/DESIGN.md)).

### Задачи

**Ошибки**
- [x] Журнал: при ошибке доступа или сети не оставлять старый счётчик «Показано N из M» и старые строки — сбрасывать список и счётчик.
- [x] Кеш статики: Rust-сервис отдаёт файлы без валидаторов, браузер после обновления показывает старые модули. Отдавать `ETag` (sha256 содержимого), отвечать `304` на `If-None-Match`, оставить `Cache-Control: no-cache`.
- [x] Мок расходится с бэкендом: журнал, входящие агента и политика (GET) должны требовать токен (`admin-demo` или `audit-demo`), изменение политики — только `admin-demo`; запись журнала для `/v1/check` без заголовка `X-Guard-Client: ui` хранится без текста (`text_stored: false`, `prompt_masked` пустой, есть `request_hash`).

**Токен в интерфейсе**
- [x] В шапке показывать, что токен введён (плашка «доступ открыт»), и давать сбросить его одной кнопкой; после сброса закрытые разделы снова просят токен.
- [x] Токен, введённый в любой вкладке (журнал, агент, политика), действует во всех остальных без повторного ввода; поле токена во вкладке «Политика» показывает, что токен уже есть.
- [x] Неверный токен не должен «залипать»: после 401/403 токен сбрасывается, форма показывается снова с понятным текстом.

**Проверка и демо**
- [x] Тесты в `frontend/tests`: токен для журнала, входящих и политики в моке; запись внешнего `/v1/check` без текста; аудитор не может менять политику.
- [x] Сценарий демонстрации на 5–7 минут в `docs/DEMO_SCRIPT.md`: какие кнопки нажимать, что говорить, что должно получиться, что делать, если модель ответила иначе.
- [x] Обновить скриншоты в `frontend/README.md`, если интерфейс заметно изменился — не потребовалось: изменились только плашка токена в шапке и форма токена.

### Готово, когда

- `node --test frontend/tests` и `cargo test` проходят.
- В браузере против Rust-сервиса: закрытые разделы просят токен один раз, работают во всех вкладках, сбрасываются; после обновления файлов на сервере обычная перезагрузка страницы показывает новую версию.
- Мок-режим ведёт себя так же, как сервис, кроме самой модели.
