# Дизайн-система «ИИ-сторожа»

Единые правила для интерфейса в `frontend/`. Все значения живут токенами в начале [css/app.css](css/app.css). Компоненты используют только токены: новый цвет, размер или отступ сначала добавляется в токены и сюда.

## Характер

Спокойная рабочая консоль безопасности. Интерфейс нейтральный и холодный; цвет появляется там, где есть смысл: решение сторожа, действие, предупреждение. Синий акцент взят из логотипа «Группы Астра», автора кейса.

## Цвет

### Роли цветов

| Группа | Токены | Для чего | Нельзя |
|---|---|---|---|
| Поверхности | `--bg`, `--surface`, `--surface-2`, `--surface-hover` | фон страницы, карточки, вложенные блоки, наведение | — |
| Текст | `--ink`, `--muted` | основной и вспомогательный текст | серый текст на цветном фоне |
| Линии | `--line`, `--line-strong` | `--line` — декоративные разделители; `--line-strong` — границы полей и вторичных кнопок (≥ 3:1) | `--line` для границ полей |
| Акцент | `--accent`, `--accent-hover`, `--accent-ink`, `--accent-soft` | главные кнопки, ссылки, активная вкладка, выбранное, реплики пользователя | для решений сторожа |
| Решения | `--allow*`, `--confirm*`, `--block*`, `--on-confirm`, `--on-block` | бейджи решений, панели доставки агенту, риск, ошибки валидации | для обычных кнопок и украшений |
| Служебные | `--info*`, `--warn*` | режим API, мок-режим, системные баннеры | для решений |
| Бренд | `--brand-navy`, `--brand-sky` | только справочно: из них выведен акцент | напрямую в компонентах |

Главное правило: **зелёный, янтарный и красный означают только allow, confirm и block**. Поэтому основные кнопки синие, а не зелёные.

### Контраст

Проверено по WCAG 2.1 для 24 пар в каждой теме: текст ≥ 4.5:1, границы полей и фокус ≥ 3:1. Ниже нормы нет ни одной пары. Самые низкие значения: `--line-strong` на `--bg` 3.22 (светлая) и `--accent` на `--accent-soft` 5.22 (светлая).

Текст на цветной заливке берёт парный токен: `--accent-ink` на `--accent`, `--on-confirm` на `--confirm`. Белый текст на янтарной кнопке в тёмной теме давал 1.85:1, поэтому там тёмный `--on-confirm`.

## Типографика

Системный шрифт, моноширинный — для кода, ID, правил политики, YAML.

| Токен | Размер | Где |
|---|---|---|
| `--fs-xs` | 12 px | метки разделов (`h3`, заглавные), мета реплик, подзаголовок бренда |
| `--fs-sm` | 13 px | подписи полей, таблицы, код, чипы, плашки, вспомогательный текст |
| `--fs-md` | 15 px | основной текст, поля ввода, кнопки, вкладки |
| `--fs-lg` | 17 px | заголовки карточек (`h2`), объяснение решения, крупный бейдж, название |
| `--fs-xl` | 22 px | заголовок страницы (`h1`) |

Насыщенность: 400 — текст, 500 — чипы и списки, 600 — подписи, кнопки, вкладки, 700 — бейджи решений и метки разделов.

## Отступы, размеры, скругления

- Отступы по сетке 4 px: `--sp-1` 4, `--sp-2` 8, `--sp-3` 12, `--sp-4` 16, `--sp-5` 20, `--sp-6` 24, `--sp-8` 32.
- Внутри карточки — `--sp-5` (на телефоне `--sp-4`), между карточками — `--sp-4`, между полями — `--sp-3`.
- Высота полей и кнопок — `--control-h` 40 px, чипов — `--chip-h` 32 px. Поля и кнопки в одной строке совпадают по высоте.
- Скругления: `--r-sm` 6 — поля, кнопки, мелкие блоки; `--r-md` 8 — карточки, баннеры, таблицы, крупный бейдж; `--r-lg` 12 — реплики диалога; `--r-pill` — бейджи, чипы, плашки.
- Вертикальные отступы между блоками в JS задаются классами `.mt-1…4`, `.mb-0`, `.mb-4`, не inline-стилями.

## Компоненты и состояния

| Компонент | Вид | Наведение | Отключено |
|---|---|---|---|
| Главная кнопка | `--accent`, текст `--accent-ink` | `--accent-hover` | прозрачность 0.5 |
| Вторичная | `--surface`, граница `--line-strong` | `--surface-hover`, граница `--muted` | 0.5 |
| Ghost | текст `--accent` | фон `--accent-soft` | 0.5 |
| Опасная | текст и граница `--block` | фон `--block-bg` | 0.5 |
| Подтверждение | `--confirm`, текст `--on-confirm` | ярче на 8% | 0.5 |
| Чип | `--surface-2`, граница `--line`, pill | `--surface-hover`, граница `--line-strong` | 0.5 |
| Вкладка | текст `--muted` | `--ink` и линия `--line-strong` | — |
| Активная вкладка | `--ink`, линия `--accent` | — | — |
| Поле | `--surface`, граница `--line-strong` | граница `--muted` | 0.55 |

Фокус для клавиатуры у всех интерактивных элементов: обводка 2 px `--focus` с отступом 2 px. Переходы 120 мс; при `prefers-reduced-motion` анимации отключены.

Бейджи решений: `allow` / `confirm` / `block` заглавными, фон `--*-bg`, текст `--*`, не переносятся. Риск в таблицах — коротко («высокий»), полное значение в подсказке.

## Бренд

- Знак продукта — щит с галочкой (`--accent` + `--accent-ink`), он же favicon `assets/favicon.svg`.
- Логотип «Группы Астра» (`assets/astra-logo.svg`, для тёмной темы — `astra-logo-on-dark.svg` с белой надписью) — только как указание автора кейса: «кейс» в шапке на десктопе и подвал. Не перекрашивать знак, не использовать как логотип продукта.
