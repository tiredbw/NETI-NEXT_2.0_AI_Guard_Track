# AstraGuard — AI Security Gateway

Проект для трека «ИИ-сторож», «Группа Астра», НЭТИ-НЕКСТ 2.0, 20–22 ноября 2026 года (даты и условия предоставлены участником).

Состояние: работают [демонстрационный веб-интерфейс](docs/UI.md), advisory API, [контролируемый demo agent](docs/STAGE_02.md) и [подтверждения с транзакционной записью](docs/STAGE_03.md). Полный P0 ещё разрабатывается; показатели качества на тестовом корпусе не измерены. Работа продукта не зависит от подписок ChatGPT/Claude и платных API.

Для запуска без ручного экспорта переменных используйте [локальный demo launcher](docs/DEMO_LAUNCH.md): `.venv/bin/python scripts/run_demo.py`.

Рекомендуемый MVP: FastAPI + Pydantic v2 + httpx + локальный Ollama/Qwen 3.5 4B + YAML + SQLite + HTML/CSS/vanilla JS. Главный принцип: семантический детектор оценивает риск, но не выдаёт полномочия; каждый реальный вызов инструмента проходит отдельную проверку.

## Проверенное окружение

- Рабочая директория: текущий корень проекта, без вложенного Git.
- Git 2.56.0; gh 2.102.0; системный Python 3.14.8. Для разработки целевая версия Python 3.12; наличие её и совместимость зависимостей ещё проверить.
- Локальный сервер Ollama 0.40.16 отвечает на `/api/version` и `/api/tags`.
- Установлена `qwen3.5:4b`, digest `7f3251fa6878a78a606bcb3c074283306e5ad2ea411a7774a9dd98a4bc7f2d13`, размер файлов 3 973 305 013 байт, runner MLX, quantization `nvfp4` по ответу сервера. Размер файлов не равен потреблению RAM.
- Apple M5 / 16 ГБ — сведения участника. Инференс, structured output и производительность в этой сессии не проверялись.

## GitHub

Создан приватный репозиторий https://github.com/tiredbw/astraguard. Первая отправка требует явного подтверждения владельца после проверки состава файлов. Пока репозиторий пуст, фактическую основную удалённую ветку нельзя установить: GitHub отклонил изменение до первого push. Локальная ветка — `main`.

Не добавлять в Git реальные запросы пользователей, журналы, базы данных, секреты и файлы авторизации. Публичную лицензию проекта пока не выбирать без решения команды.
