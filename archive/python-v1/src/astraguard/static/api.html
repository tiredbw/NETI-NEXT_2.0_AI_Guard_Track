AstraGuardAI Security Gateway

API для локальной интеграции

Полная машиночитаемая схема: OpenAPI JSON. Все защищённые маршруты требуют заголовок Authorization: Bearer TOKEN. Ключ берётся из вашей локальной конфигурации; эта страница не выдаёт credentials.

МаршрутНазначение
POST /v1/sessionsСоздать серверную сессию
POST /v1/checksПроверить без исполнения
POST /v1/agent/turnsПроверить и передать агенту при ALLOW
GET /v1/checksИстория в пределах полномочий
GET /v1/reviews/{id}Описание точного действия для reviewer
POST /v1/reviews/{id}/approveВыдать одноразовое подтверждение
GET /v1/statsСтатистика tenant для reviewer

Пример тела проверки

{
  "text": "Объясни prompt injection",
  "session_id": "UUID созданной сессии",
  "policy_id": "strict-demo-v1"
}

REVIEW и BLOCK останавливают передачу агенту. Для исполнения подтверждённого действия передайте approval_id и Idempotency-Key, сохранив исходные поля запроса. Ошибки имеют формат error.code, error.message и error.request_id.

Эта справка работает без внешних CDN. Подробные контракты и ограничения находятся в docs/API.md и документах этапов в репозитории.
